# php-control-practice

## 概要
COACHTECH 教材 Tutorial 7-2「制御構文 ハンズオン演習」で作成した成果物です。
学生の氏名、各自の点数、合格点を変数で定義し、各自の点数、合格者数・不合格者数・平均点を表示するシステムです。

## 使用技術
- PHP 8.x
- foreachでのループ処理

## 学んだこと
- foreachの使い方
- 変数定義のおさらい、順序立てて定義していくこと
- 処理１つずつに対しコメントを残すことで、修正しやすくなること
